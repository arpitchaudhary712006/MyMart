ℹ️ How My Mart works

My Mart is a full-stack online grocery store: a Flask REST API (backend) talks to a SQLite database, and a HTML/CSS/JavaScript frontend calls that API with fetch(). Everything runs on your own computer at http://localhost:5000.

The same Flask server also serves the frontend files, so there is only one thing to start.

🛍️ Customers can

  • Register and log in securely (passwords are hashed)
  • Search and filter products by category, veg-only, or in-stock
  • Sort by popularity, price, discount, rating, or newest items
  • Add items to cart and adjust quantities with live stock checks
  • Checkout via UPI QR code or Cash on Delivery (COD)
  • Track order delivery status and cancel orders before shipment

🛠️ Admins can

  • Monitor key KPIs: total revenue, order count, and customer metrics
  • Analyze sales trends by month, category, product, city, and payment method
  • Add, edit, restock, or remove products in the catalog
  • Manage the order fulfillment workflow (Placed → Packed → Shipped → Delivered)
  • View customer lists, total spend, and manage store data
